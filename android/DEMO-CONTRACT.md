# 차량 앱과 시연의 공통 기준

> 이 문서는 Android 입력 `479db2bc4e55bd58e9cda1f9408ea294e1c8ebf3`의 계약과 당시 차이 기록이다. 통합 작업은 Android 코드·리소스를 유지하고 HTML의 기본 3출처, 08:40/08:54, 45/12초 예산, 11/8/13초 추정치, 제목과 커뮤니티 우선순위를 맞췄다. 4분 커뮤니티 단독은 예산 초과로 재생·저장을 막고 도착 poster도 재생하지 않는다. 실제 동기화·실차 상태 검증은 여전히 없다. [통합 근거](../integration-notes.md).

기준: `94fa9ca1324029c07a8cee25b7771bb4f007e215`. 기존 `showcase/REHEARSAL.md`의 18분 게임→저장→4분 회의→도착 후 확인 순서를 유지합니다. 이 작업은 `android/`만 수정하며 시연 쪽 변경은 포함하지 않습니다.

샘플 날짜는 2026-11-05, 시각은 Asia/Seoul입니다. 8/11/13초는 추정치입니다. 32초를 실제 음성 실측으로 소개하지 않습니다. 차량 상태는 샘플 ETA와 독립적입니다. UX 허용은 기어 P를 직접 확인했다는 뜻이 아닙니다. 시연의 주차 표시는 샘플 연출인지 실차 상태인지 명시해야 합니다.

실제 앱의 저장은 해당 패키지의 SharedPreferences에 남습니다. HTML에서 휴대폰에 저장되는 장면은 기존 시연 연출이며, 실제 기기 간 동기화로 설명하지 않습니다. NAVI_HELPER 모드에는 예시 관측 시각을 넘기지 않습니다. 실제 모드가 실패하면 샘플 시간 대신 ETA 미확인을 표시합니다.

## 글꼴과 색상

[Pleos Typography](https://document.pleos.ai/docs/connect/guide/docs-design/foundations/typography)가 안내하는 Asta Sans를 사용합니다. `res/font/asta_sans.ttf`는 수정하지 않은 Google Fonts 가변 글꼴이며 [고정 소스](https://github.com/google/fonts/tree/fbe81817505e8aeadc53cc7a38a2b76fb57c333e/ofl/astasans)를 사용했습니다. SHA-256: `f68410bf7d04deb992097758640145c72ddcf234070794237fc4994e18991c33`. 시연 브랜치의 Asta Sans와도 SHA-256이 같습니다. OFL 1.1과 저작권 고지는 APK의 `assets/licenses/AstaSans-OFL.txt`에 동봉합니다. 현대차 별도 서체는 사용하지 않았습니다.

[Pleos Colors](https://document.pleos.ai/docs/connect/guide/docs-design/foundations/colors)의 Background/Surface/Text/Button 역할을 다음 앱 리소스에 매핑했습니다. **공식 이미지의 원시 토큰 값을 추출·대조하지 못했으므로 공식 토큰과 숫자가 일치한다고 주장하지 않습니다.** 아래는 시연 브랜치 `3ff697d261e417fa6a2ff18ddcb91ebd83c32a6a`의 `showcase/DESIGN-SOURCES.md`와 대조해 맞춘 앱 색상입니다.

| 앱 역할 | 주간 | 야간 |
| --- | --- | --- |
| Background | #EEF0F3 | #111214 |
| Surface | #FFFFFF | #1D1F23 |
| Border | #808996 | #565C66 |
| Text | #171A1F | #F5F6F7 |
| Secondary Text | #505866 | #B7BEC8 |

실제 리소스로 계산한 활성 텍스트 최소 대비는 주간 6.28:1, 야간 8.81:1입니다. 비활성 버튼은 낮은 불투명도로 구분합니다. 본문 최소 18sp, 제목 28/34sp, ETA 48sp, 버튼 최소 높이 56dp입니다. 글꼴 확대 시 내용은 스크롤하며 가로·세로 창을 수용합니다. 기기 렌더링에서 긴 한글·대화상자·확대·좁은 창이 잘리지 않는지는 실기 검증이 남았습니다.

[Pleos Display Layout](https://document.pleos.ai/docs/connect/guide/docs-design/getting-started/layout)에 따라 앱 콘텐츠만 그립니다. 시스템 상태 표시줄, Driving view, GNB·공조를 앱 안에 복제하지 않습니다. WindowInsets로 시스템 영역을 비우며, 가장 먼저 ETA와 이번 소식, 기본 듣기 동작을 배치하고 경로 전환·출처 설정은 아래로 내렸습니다.

## 입력 커밋 당시의 통합 보류 항목 · 과거 비교

2026-11-05에 시연 브랜치 `codex/showcase-pleos-redesign-20261105`의 커밋 `3ff697d261e417fa6a2ff18ddcb91ebd83c32a6a`를 읽어 대조했습니다. 두 작업의 merge-base는 같은 기준 커밋입니다. `showcase/` 변경을 이 브랜치로 병합하지 않았습니다.

- 시연의 `약 2분` 게임 / `약 40초` 회의는 앱의 게임 11초 / 회의 8초 추정치 및 전체 45초 / 12초 예산과 다릅니다. 시연 표시를 고쳐야 같은 편성으로 소개할 수 있습니다.
- 시연 시계는 08:42 / 08:56, 앱 예시 시각은 기존 기준인 08:40 / 08:54입니다. 앱의 마감은 08:58입니다. 시연을 앱 기준으로 맞춰야 합니다.
- 시연 기본 출처는 커뮤니티가 꺼져 있고, 앱은 세 출처 모두 켜짐입니다. 32초·3건을 재현하려면 시연에서도 세 출처를 켜야 합니다.
- 회의 제목은 앱 `9시 팀 회의가 3층으로 바뀌었어요`, 시연 `9시 회의, 3층 라운지로 변경`입니다. 내용은 같지만 표시 문자열 통합은 남았습니다.
- 시연의 `주차 중 · 브리핑 이용 가능`은 샘플 P 연출입니다. 앱은 플랫폼 UX 허용을 받아 `주차 시 사용 가능 · 차량 UX 제한 해제`로 표시하며 실제 기어 P 판정으로 과장하지 않습니다. 제한/미확인 상태의 문구도 위 표를 기준으로 대조해야 합니다.
- HTML의 localStorage 저장과 앱의 SharedPreferences 저장은 각각 한 기기에서만 실제 동작합니다. 자동 휴대폰 저장 장면은 연출이며 상호 동기화가 아닙니다.

위 목록은 입력 커밋 당시 차이다. 통합본에서 수정한 항목과 재검증 범위는 문서 상단 및 통합 기록으로 확인한다.
