# 차량 앱 담당 인계

- 독립 시작점: `94fa9ca1324029c07a8cee25b7771bb4f007e215` (`main`). Android 작업과 합치지 않은 독립 시연 변경이다.
- 변경 소유권: `showcase/`만. `android/`, 루트 기획서, 기존 Cloud 지시서를 수정하지 않았다.
- 공통 샘플: 회사까지 18분, 가상 게임 패치 ‘이번 주말, 협동 모드가 열려요’, 오전 9시 팀 회의 ‘3층 라운지로 변경’. 4분 남으면 켜 둔 일정이 먼저다.
- HTML의 출처 선택·순서·저장은 localStorage 한 브라우저에서만 실제 동작한다. 계정·서버·휴대폰·Android 동기화 계약은 구현하지 않았다. Android 저장을 검증한 것으로 해석하면 안 된다.
- 자동 시연의 저장 완료·도착 후 휴대폰은 연출이다. 자동 시연은 localStorage를 변경하지 않는다. 사용자가 저장 버튼을 눌렀을 때만 실제 저장한다.
- 제한·차량 상태 미확인 장면에서는 두 앱 동작을 비활성화하고 재생 상태를 초기화한다. 실제 SDK 콜백이나 오디오 포커스·TTS 테스트 근거가 아니다.
- Steam 연결은 환경의 목적지 제한 때문에 403이다. 실제 API 콘텐츠를 샘플 게임 제목으로 대체했다. `evidence/steam-source.json`에 원문 경로·조회 시각·실패·fallback을 기록했다. 실시간 성공 주장을 추가하지 않는다.
- Asta Sans는 이 시연에만 동봉했다. Android로 옮길 경우 `assets/fonts/OFL.txt`와 출처도 함께 포함한다. Hyundai Sans UI는 배포 조건 미확인으로 사용하지 않았다.
- 실제 차량 앱과 통합할 때 바인딩할 것은 ETA/상태, 선택 출처/순서, 저장 항목이다. 현재 HTML은 Pleos UI 예시이며 네트워크·차량 하드웨어 없이 실행된다.
