# 도착 전에

업무 일정과 관심 소식을 목적지까지 남은 시간에 맞춰 골라 읽어 주는 Pleos 차량용 출근 브리핑 앱입니다.

## 실행 방법

1. 에뮬레이터를 시작하고 저장소 루트에서 `adb install "apk/최재훈_도착전에_release.apk"`를 실행합니다.
2. Pleos 기본 내비에서 코엑스 또는 노선버스 전용 공영차고지로 안내를 시작한 뒤 ‘도착 전에’를 엽니다. 도착 시간이 표시되지 않으면 **실제 경로 다시 연결**을 누릅니다.
3. 정차 상태에서 **브리핑 듣기**를 눌러 서윤 음성으로 편성된 소식을 듣습니다.

## 테스트 환경 및 필요한 설정

Windows x64에서 Android Automotive API 34 기반 Pleos 에뮬레이터와 ADB를 사용했습니다. 실제 내비 안내를 시작한 상태에서 테스트합니다. 긴 코엑스 경로에서는 업무 일정, 커뮤니티, 게임 소식 순으로 세 건을 확인했고, 공영차고지 5분 경로에서는 업무 일정 한 건과 서윤 음성 재생을 확인했습니다. 업무 일정과 커뮤니티 글은 시연용 예시입니다.

## Pleos Connect 에뮬레이터 버전 및 화면 규격

Pleos Connect Emulator 2.1.0, 가로 2560 × 1440 px (16:9).
